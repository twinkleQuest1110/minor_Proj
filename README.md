
# 🎉 RENTEL - Celebrate More, Own Less

### A Celebration Essentials Rental Marketplace

RENTEL is a web-based rental marketplace where users can rent celebration essentials instead of purchasing expensive products for one-time use.

The platform aims to connect customers with renters who provide products such as fashion outfits, party essentials and decorations at affordable rental prices.

---

## 📌 Project Overview

Many people spend money purchasing expensive items for weddings, birthday parties, festivals and other special occasions.

RENTEL provides a convenient solution by allowing users to rent these products for a specific period.

**Our tagline:** Celebrate More. Own Less.

---

## 🎯 Objectives

- Provide an affordable rental platform.
- Reduce unnecessary product purchases.
- Connect customers with product renters.
- Make product discovery and rental booking easier.
- Encourage the reuse of products.

---

## ✨ Features

### 👤 Customer
- Browse available rental products.
- Explore different product categories.
- Search for products.
- View rental prices and security deposits.
- Rent products for special occasions.

### 🏪 Renter
- Add rental products.
- Manage product listings.
- Set rental prices and security deposits.
- Manage customer booking requests.

### 🛡️ Admin
- Manage customers and renters.
- Manage product listings.
- Monitor rental bookings.
- Manage platform activities.

*Note: Customer, Renter and Admin features are planned modules. Their implementation will be added progressively.*
